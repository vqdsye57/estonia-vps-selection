## 实际使用中容易踩的坑

### 1 GB 内存真的跑不了 Windows

EDIS Global 的 KVM Smart（€4.99/月）和 servinga 的 VPS B1C1（5€/月）都明确标注"不适合 Windows Server"或"仅支持 Linux"。

Windows Server 2019 最低内存要求是 512 MB，但那是能启动，不是能用。实际跑起来至少要 2 GB，否则频繁换页会把性能拖垮。如果你一定要用 Windows，至少选 EDIS Global 的 KVM Basic Plus（€14.69/月，2 核 4 GB）。

### 流量限制的真实含义

EDIS Global 用的是"Traffic Pool"机制：每个 VPS 包含 100 GB 启动流量额度，流量池中的流量永不过期。如果你这个月套餐包含 1 TB 但只用了 500 GB，剩下 500 GB 会自动滚到下个月。对流量波动大的项目来说实用。

Infrawire 和 is*hosting 标的"无限流量"（Unmetered Bandwidth）实际受端口速率限制。比如 Infrawire VPS Entry 的网络是 2.5 Gbps，理论跑满一个月也就 800+ TB，但现实中很少有人真跑满。

### 端口 25 和邮件服务

Infrawire 明确写了"除端口 25 外所有端口开放"。端口 25 是 SMTP 的标准端口，被封是为了防垃圾邮件滥用。

如果你要搭邮件服务器，得改用 587（SMTP submission）或 465（SMTPS），或者走 SendGrid、Mailgun 这类第三方 SMTP 服务。

### 增值税的实际支付

EDIS Global 和 EstNOC 的价格不含增值税，欧盟内个人用户会被加税（通常 20%）。如果你从欧盟外订购或提供有效的欧盟增值税号，就不用交。

Infrawire 的价格已含税，看到多少就付多少。

is*hosting 提供"is*smart"优惠计划，能在标价基础上再省约 5%，但需要注册会员。
